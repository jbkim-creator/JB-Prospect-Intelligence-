## C. 증빙 수집 규격
| field | Required | Description |
|---|---|---|
| company_id | Y | 분석 대상 |
| question_id | Y | 고정 질문 ID |
| prompt | Y | 정확히 입력한 질문 |
| provider | Y | ChatGPT / Gemini / Perplexity 등 |
| model | Y | 화면/응답에 표시된 모델명 또는 unknown |
| observed_at | Y | ISO8601 시각 및 시간대 |
| locale | Y | 국가·언어 |
| session_id | Y | 독립 세션/반복 여부 |
| response_text | Y | 답변 원문 |
| citation_urls | N | 실제 인용 링크 목록 |
| capture_ref | Y | 권한 있는 스크린샷 또는 저장 원문 경로 |
| target_mentioned | Y | true/false |
| competitors_mentioned | Y | 확인된 경쟁사 명칭 |
| sentiment_context | Y | 긍정/중립/부정/불명 |
| verified_by | Y | 검토자 및 검토일 |

**보안:** 환자·개인 고객 정보 등 민감 자료 입력 금지. 원문은 고객 승인 범위에서만 처리.

## D. 주요 지표
- 브랜드 언급률 = 브랜드가 등장한 유효 응답 수 / 전체 유효 응답 수
- 경쟁사 언급률 = 해당 경쟁사 등장 응답 수 / 전체 유효 응답 수
- 브랜드 인용률 = 브랜드 공식 도메인이 인용된 응답 수 / 인용 지원 응답 수
- 질문별 평균 / 플랫폼별 평균 / 언어별 평균 분리
- 부정적 언급과 단순 명칭 등장은 추천으로 간주하지 않음
- 표본 크기가 작으면 비교결과는 방향성 참고로만 표시

## G. 해석 및 면책
AI 응답은 모델·설정·시점·지역에 따라 달라집니다. 본 진단은 검색 순위나 고객 획득을 보장하지 않습니다. 사용자가 확보한 답변 원문과 질문군에 대한 관찰로서, 전체 이용자 환경의 통계적 대표성을 주장하지 않습니다.
