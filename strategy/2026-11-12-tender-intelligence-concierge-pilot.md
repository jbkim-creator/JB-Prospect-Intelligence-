# JB Tender Intelligence — 최소개발·유료 파일럿 검증계획
기준: 2026-11-12

## 보류 결정
- 범용 입찰 알림/대량 API 동기화/SaaS 대시보드 신규 투자 일시 중단.
- 현재 정적 데모와 기존 소스는 보존. 단독 프로그램이 실시간/완전한 자격 판단을 수행한다고 광고 금지.

## 실험 고객
- 화신엔지니어링: 상하수도·정수장·건설사업관리 공고, PQ 검토. 공식 사업팀 확인 전 영업 수신처 추정 금지.
- 드림이앤디: 산업단지·도시개발·토목 엔지니어링 공고. 공식 회사 사이트와 대표전화 이용한 수주기획 부서 확인 필요.
- 한맥기술: 도로·교통·수자원·CM. 분야별 부서 연락 경로는 조사 이력에 존재하나 계약 책임자 미확인.
- 각 기업 실질 업무 담당자와 논의 전에는 구매의사 확인으로 분류하지 않음.

## 시험 산출물
- 공식 나라장터 공고 원문 **최근 유효한** 3건. 공고번호, 기관, 기초금액, 마감, 지역/업종/면허, 제한, 컨소시엄, 정정/취소 여부, 주요 PQ 조건.
- 결과: 적합 / 추가 확인 / 부적합 및 판단 근거와 사람이 최종 확인할 항목.
- 제안 가격 월 19만~49만원은 과업/검수/부가세 확정 전 가격 가설.
- 부가가치: '공고 알림'이 아니라 **입찰 참여 전 시간절약·규정 리스크 감소**.
- 신뢰성 게이트: 공식 원문 확인 없는 제3자 포털 샘플을 실제 유효 공고로 제시하지 않음.

## 실행과 철수 기준
1. 3사 각각 실제 부서/수신 창구 확인 → 공고 유형 및 PQ 필수정보 파악
2. 공식 유효 공고 3개 이상 실사 → 회사별 1페이지 무료 검토 샘플
3. 담당자 5회 유효대화 또는 샘플 검수 5건 후 유료 관심 0건: 유료 SaaS 개발은 유지 중단
4. 유료 계약/반복 구매 실증 전 인력 및 개발시간 최소화, Netlify 신규 운영배포 없음

## 현재 상태
준비 및 샘플 단계, 유료 고객·수금 0건 확인. 자동 실시간 G2B API 연동 검증되지 않음.
