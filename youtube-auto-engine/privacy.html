JBRO YouTube Auto Engine

개인정보처리방침

이 방침은 운영자가 관리하는 YouTube 채널 @JBROBusinessKits의 제작·게시 도구인 JBRO YouTube Auto Engine에 적용됩니다.

운영자와 문의

운영자는 제이브로캐피탈 유한책임회사입니다. 개인정보 열람·정정·삭제 및 동의 철회 문의는 jbkim@jbrocap.com으로 보내 주세요.

접근하는 정보와 이용 목적

Engine은 YouTube API Services의 YouTube Data API v3를 사용합니다. 채널 운영자가 Google 동의 화면에서 권한을 부여하면 OAuth 자격 증명을 받아 후속 작업에서 사용합니다. Google 개인정보처리방침은 Google에서 확인할 수 있습니다.

  • youtube.readonly 권한으로 인증된 채널 ID, 업로드 목록, 영상 ID와 제목·설명·게시일·길이, 공개 및 처리 상태를 조회합니다. 대상 채널 확인, 중복 업로드 방지, 게시 결과 확인에 사용합니다. 노출 확인 실행은 조회수·좋아요 수·댓글 수도 조회합니다.
  • youtube.upload 권한으로 검토된 영상 파일과 제목·설명·공개 설정을 YouTube에 전송합니다. 업로드 전용 실행은 관리자가 지정한 에피소드를 처리합니다. 인증 확인 실행은 채널과 기존 영상 정보를 조회합니다.

저장 및 외부 처리

OAuth 자격 증명은 인증을 실행한 환경의 토큰 파일과 비공개 GitHub 저장소의 GitHub Actions 비밀 저장소에서 관리합니다. 게시 상태 파일에는 에피소드별 영상 ID와 처리 상태가 남을 수 있습니다. 검증 및 노출 확인 결과는 GitHub Actions 실행 로그에 기록될 수 있습니다.

GitHub Actions에서 자동화를 실행하며, 미리보기 제작 워크플로의 영상 산출물은 3일 보관으로 설정되어 있습니다. 일부 제작 경로는 내레이션 문장을 Microsoft Edge 음성 합성 서비스에 전송합니다. Google은 OAuth 인증, YouTube 데이터 조회 및 영상 게시를 처리합니다. Actions 로그는 저장소의 로그 보관 설정에 따라 만료됩니다. 중복 게시 방지에 필요한 게시 기록은 채널 운영 중 보관하며, 인증을 해제하거나 삭제 요청을 접수하면 해당 인증으로 가져와 저장한 API 데이터와 인증 정보의 삭제를 처리합니다.

동의 철회와 삭제

Google 계정의 연결 설정에서 앱 액세스를 철회할 수 있습니다. 보관 중인 인증 정보와 API 데이터의 삭제는 위 이메일로 요청할 수 있습니다. 연락 시 채널 또는 에피소드 식별 정보를 알려 주세요. 비밀번호와 토큰은 보내지 마세요.
