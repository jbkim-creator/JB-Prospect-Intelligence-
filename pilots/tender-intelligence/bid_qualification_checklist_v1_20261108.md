# JB Tender Intelligence — 입찰공고 고객제출 검증 체크리스트 v1
작성일 2026-11-08

## 필수 데이터 필드
- 공고번호 + 차수 + 구분(용역/물품/공사)
- 공식 조달청 입찰공고 원문 URL
- 발주기관 / 수요기관
- 공고 최초 게시일 / 정정일 / 마지막 수집시각
- 입찰참가 등록 마감 / 공동수급 협정서 마감 / 투찰 마감 (시간대 KST)
- 기초금액 vs 추정가격 vs 예산액 — 각 금액의 의미 구분
- 참가자격 면허, 업종, 지역제한, 유사실적, 기술인력, 계약방법
- 정정·취소·재공고 이력
- 첨부 제안요청서, 과업지시서, PQ/적격심사 기준 링크
- 고객사 적합성: **추정(자동)** / **서류확인(검토자)** / **참가가능 최종판단(고객)** 별도 표시

## 공고 평가 규칙(초기 가설)
1. 관심 산업·과업 키워드 일치 0~30점
2. 수행 지역·조직 역량 0~15점
3. 계약 규모·투입 인력 적합성 0~15점
4. 면허·실적·인력 참가조건 0~30점 (고객사 제출 자료가 없다면 '미확인' 및 점수 미산정)
5. 마감까지 남은 준비기간 0~10점
6. 정정·취소 등 위험: 플래그만, 원문 확인 필수

**주의:** 현재 정적 MVP의 키워드 점수는 1차 필터일 뿐이며, 위 기준에 따른 실제 요건심사 기능은 구현 전임.

## 보고서 출고 게이트
- [ ] 조달청 공식 원문 재열람
- [ ] 정정/취소 여부 점검
- [ ] 모든 금액·마감 시간 교차 확인
- [ ] 고객의 면허/실적 체크리스트 확보
- [ ] 고위험·불명확 사항에 '미확인' 표기
- [ ] 최종 검토자, 검증 시각, 원문 URL 기록
- [ ] 발송 전 고객 동의 및 수신 적법성 확인

## 첫 고객 테스트 지표
- 기존 방식 대비 실제 검토시간 절약률
- 주간 공고 적중률 (고객이 유효하다고 평가한 공고 / 전달 공고)
- 정정공고 누락률 및 오탐률
- 14일 유료 전환 의향 확인
