# JBRO Security Audit — 유료 상담·견적 준비 패키지
작성일: 2026-11-16

## 1. 최초 회신을 받았을 때 확인할 정보
- 법인명 / 담당자 / 회신 이메일
- **자체 소유 또는 합법적으로 권한을 가진 자산**인지 확인 (제3자 자산은 법적 권한 증빙 필요)
- 도메인, 서비스 운영환경, 진단 목적, 요구 보고일
- 서비스 단절 위험과 금지된 테스트 종류
- 진단 가능 시간대 / 비상 연락 경로
- 클라우드·호스팅 사업자 약관상 검사 가능 범위
- 개인정보·로그·인증정보는 상담 첫 메일로 받지 않음

## 2. 99만원부터의 단발성 상세 진단 — 최초 제안 예시
**제안 가격**: 990,000원부터(부가세 별도), 범위·예산·전문가 확보에 따라 조정

**포함 검토** (각 항목은 범위와 승인 확정 시)
1. 자산·권한·진단 시간·허용 도구를 정한 Rules of Engagement 서면 합의
2. 승인된 도메인에 대한 공개 DNS·이메일 인증 설정 점검
3. 승인된 서비스에 대한 TLS·HTTP 보안 헤더 구성 검증
4. 시스템 구조·노출면·권고사항의 전문가 확인
5. 경영진 요약·우선순위·담당자·개선 기한이 담긴 보고서
6. 개선 관련 1회 이메일 후속 질의응답

**별도 범위/견적**: 침투 테스트, 코드 검토, 클라우드 내부 설정, 로그인 후 스캔, 개인정보 취급/컴플라이언스 인증, 사고 대응, 재검증, 지속 모니터링

## 3. 파일럿 제휴 제안
- 제휴사 한 곳의 **사전 승인된** 관리 고객 1개사만 선정
- JBRO 무료 도구를 사용한 고객 자가점검 체험
- 도구 사용성·오탐·응답시간·고객 의견 확보 (고객 도메인과 개인정보를 무단 저장하지 않음)
- 상세 진단 수요 발생 시, 실제 계약·수익배분 별도 서면 협의
- 수수료율·결제조건은 아직 확정되지 않았으며, 성사 보장은 하지 않음

## 4. 초기 제안 메일 회신 초안
안녕하세요.

관심 가져 주셔서 감사합니다. 안내드린 무료 서비스는 공개 DNS 및 HTTPS 기본 설정을 확인하는 자가진단이며, 침투 테스트나 전체 취약점 평가는 포함하지 않습니다.

유료 상세 진단은 99만원부터(부가세 별도) 제안하고 있으며, 실제 견적은 고객이 승인한 자산·도메인 수, 검사 범위, 일정 및 전문가 검토 수준을 확인한 후 확정됩니다.

진단이 필요한 도메인 수, 사이트 운영 형태(SaaS/쇼핑몰/기업 홈페이지), 원하는 검토 범위와 희망 일정만 먼저 알려주실 수 있을까요? 비밀번호·API 키·개인정보·접속 권한은 지금 보내지 않으셔도 됩니다.

감사합니다.

## 5. 내부 수익 검토
- 건당 99만원은 **최저 제안 가격**이며 확정 매출이 아님
- 외부 보안 전문가의 시간당/건당 비용, 고객 요구사항, 사고배상책임, 재작업 비용을 확정하기 전에는 고정범위와 이익률 보장 불가
- 예시: 수주금액 99만원에서 전문가 외주비 45만원·기타 직접비 10만원 발생 시 기여이익 44만원(부가세 제외; 법인 운영비 및 세금 전, 가정치)
- 정기관리 월 79만원 상품은 실제 검증 가능한 관리 항목과 이행 책임에 맞춰 별도 계약

## 6. 운영상 주의
- 공식 이메일 영업은 최초 1회 중심으로 제한; 기존 발송 스레드 존중 및 수신 거부 즉시 준수
- 고객의 동의 없는 취약점 탐색·진단 금지
- 무료 웹 진단과 실제 유료 전문가 진단을 혼동시키지 않도록 고지
- 사업자 정보·약관·개인정보 안내·실제 기능 QA 완료 전 대규모 캠페인 지양
