무료 점검 결과는 어떻게 활용하나요?

결과가 ‘개선 권장’이라고 표시되면 해당 설정을 담당자와 확인하고 서비스 운영환경에 맞춰 변경해야 합니다. 변경 전 이메일 발신 시스템, 웹서비스 구성과 영향 범위를 확인하세요.

검사 범위와 제한

HTTPS 첫 페이지로 HEAD 요청 1회를 보냅니다. 리다이렉트·로그인 이후 화면·코드 취약점·침투 테스트는 수행하지 않으며 전체 보안 안전을 보증하지 않습니다.
