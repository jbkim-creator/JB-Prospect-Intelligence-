# JB Prospect Intelligence

Official marketing landing page for JB Growth Lab / Jbro Capital Ltd.

## Deployment

Deploy this static site from the repository root with Netlify. Build command: none; publish directory: `.`.

Enable Netlify Forms, configure email notification to `jbkim@jbrocap.com`, then submit a test form. Do not treat this repository as customer data storage.

Pricing: Pilot 30, KRW 390,000 excluding VAT. Information and privacy text must be reviewed before accepting real customer submissions.
